# Cloudflare-CustomErrorRules

1.This is the Cloudflare Custom Error Rules style for my personal website. Feel free to download the code and modify it for use on your own site.

2.You may notice the page appears abnormal during preview — this is normal, no need to worry. Please test the actual trigger page directly.

3.The page uses an overall black-and-yellow theme and automatically adapts to Chinese, Japanese, and English based on the browser language.

4.Some pages currently have adaptation issues on mobile devices, which may be fixed later.


1.这是我的个人网站的Cloudflare自定义错误规则样式，您可以自行下载代码进行修改在自己网站使用。

2.您可能会在预览时候发现页面异常，这是正常的，无需担心。请直接测试真实触发页面。

3.页面整体采用黑黄风格，浏览器自适应中日英语言。

4.目前存在移动端部分页面适配性问题，也许后面会修复。
